# mise-hub M0 + M1 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 做出 mise-hub 的第一个可用版本：能启动、能添加项目、能发现 mise 支持的工具、选版本并安装、在底部终端面板看到进度。

**Architecture:** 两个 crate 的 workspace。`mise-core` 是纯 Rust 库，负责定位 mise、调用 CLI、解析 JSON、本地搜索、项目持久化，不依赖 GPUI，全部可单测。`mise-hub` 是 GPUI Kit 桌面应用，只负责状态与渲染，所有 mise 交互都经过 `mise-core`。

**Tech Stack:** Rust 2024 edition、`gpui-kit = "0.7.3"`、`serde` / `serde_json`、`thiserror = "2"`、`directories = "6"`、`rust-i18n = "4.2"`、`tempfile`（dev）。

**Spec:** `docs/superpowers/specs/2026-10-19-mise-hub-design.md`

## Global Constraints

- mise 一律通过**子进程 CLI** 调用，不链接 mise 源码、不重实现配置语义。
- 所有 mise 调用带 `-C <项目目录>`（全局调用不带），顺序是 `mise -C <dir> <subcommand> ...`。
- 写配置只用 `mise use` / `mise set` / `mise unset`，M0/M1 不直接写任何 `mise.toml`。
- 搜索只支持英文关键词；不做中文标签层。
- 安装（`mise install`）与生效（`mise use`）是两个独立动作，M1 只做安装。
- 项目只由用户手动添加，**不自动扫描**任何目录。
- 优先 macOS，但代码里不写死 macOS 路径；Windows / Linux 必须能编译。
- 界面文案中英双语，默认跟随系统语言，可切换。
- mise 缺失、退出码非 0、JSON 非法时都必须进入错误状态，不能 panic 或卡死。
- 每个任务结束提交一次。

## Review Focus

1. **registry JSON 缺字段**：`description` / `aliases` / `bins` / `backends` 缺失时不能 panic，必须用 serde 默认值。
2. **`ls --json` 里 `source` 为 null 或缺失**：范围归类不能 panic，默认归为 `Global`。
3. **带后端前缀的工具名**（如 `npm:prettier`、`cargo:ripgrep`）和大小写：搜索与安装参数必须原样传递，不能被拆分或改写。
4. **空搜索词**：发现页应返回按字母排序的完整列表（浏览），不是空结果。
5. **mise 不存在 / 非 0 退出 / 返回非法 JSON**：界面显示可读错误，进程不崩溃、不阻塞。

```rust
use crate::error::CoreError;
use std::path::PathBuf;
use std::process::Command;

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct CommandRequest {
    pub program: PathBuf,
    pub args: Vec<String>,
    pub cwd: Option<PathBuf>,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct CommandOutput {
    pub code: i32,
    pub stdout: String,
    pub stderr: String,
}

pub trait CommandRunner: Send + Sync {
    fn run(&self, req: &CommandRequest) -> Result<CommandOutput, CoreError>;
}

pub struct ProcessRunner;

impl CommandRunner for ProcessRunner {
    fn run(&self, req: &CommandRequest) -> Result<CommandOutput, CoreError> {
        let mut cmd = Command::new(&req.program);
        cmd.args(&req.args);
        if let Some(cwd) = &req.cwd {
            cmd.current_dir(cwd);
        }
        let out = cmd.output()?;
        Ok(CommandOutput {
            code: out.status.code().unwrap_or(-1),
            stdout: String::from_utf8_lossy(&out.stdout).into_owned(),
            stderr: String::from_utf8_lossy(&out.stderr).into_owned(),
        })
    }
}
```

```rust
use std::path::{Path, PathBuf};

pub fn locate_in(path_dirs: &[PathBuf], candidates: &[PathBuf]) -> Option<PathBuf> {
    for dir in path_dirs {
        let candidate = dir.join(if cfg!(windows) { "mise.exe" } else { "mise" });
        if is_executable(&candidate) {
            return Some(candidate);
        }
    }
    candidates.iter().find(|p| is_executable(p)).cloned()
}

pub fn default_candidates() -> Vec<PathBuf> {
    let mut out = Vec::new();
    if let Some(home) = std::env::var_os("HOME").map(PathBuf::from) {
        out.push(home.join(".local/bin/mise"));
        out.push(home.join(".cargo/bin/mise"));
    }
    out.push(PathBuf::from("/opt/homebrew/bin/mise"));
    out.push(PathBuf::from("/usr/local/bin/mise"));
    out
}

pub fn locate_mise() -> Option<PathBuf> {
    let path_dirs = std::env::var_os("PATH")
        .map(|p| std::env::split_paths(&p).collect::<Vec<_>>())
        .unwrap_or_default();
    locate_in(&path_dirs, &default_candidates())
}

fn is_executable(path: &Path) -> bool {
    path.is_file()
}
```

```rust
use crate::types::ToolEntry;

pub struct SearchIndex {
    entries: Vec<ToolEntry>,
}

pub struct SearchHit {
    pub tool: ToolEntry,
    pub score: i32,
}

impl SearchIndex {
    pub fn new(entries: Vec<ToolEntry>) -> Self {
        Self { entries }
    }

    pub fn search(&self, query: &str, limit: usize) -> Vec<SearchHit> {
        let q = query.trim().to_lowercase();
        let mut hits: Vec<SearchHit> = if q.is_empty() {
            self.entries
                .iter()
                .map(|e| SearchHit { tool: e.clone(), score: 0 })
                .collect()
        } else {
            self.entries
                .iter()
                .filter_map(|e| score(e, &q).map(|s| SearchHit { tool: e.clone(), score: s }))
                .collect()
        };
        hits.sort_by(|a, b| b.score.cmp(&a.score).then_with(|| a.tool.short.cmp(&b.tool.short)));
        hits.truncate(limit);
        hits
    }
}

fn score(tool: &ToolEntry, q: &str) -> Option<i32> {
    let short = tool.short.to_lowercase();
    if short == q {
        return Some(1000);
    }
    if short.starts_with(q) {
        return Some(800);
    }
    if short.contains(q) {
        return Some(600);
    }
    if tool.aliases.iter().any(|a| a.to_lowercase() == q) {
        return Some(550);
    }
    if tool.aliases.iter().any(|a| a.to_lowercase().contains(q)) {
        return Some(500);
    }
    if tool.bins.iter().any(|b| b.to_lowercase() == q) {
        return Some(450);
    }
    if tool
        .description
        .as_deref()
        .is_some_and(|d| d.to_lowercase().contains(q))
    {
        return Some(300);
    }
    None
}
```

```rust
    Project,
    Global,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum ScopeFilter {
    All,
    Project,
    Global,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct ToolRow {
    pub name: String,
    pub version: String,
    pub requested_version: Option<String>,
    pub scope: Scope,
    pub active: bool,
    pub install_path: Option<PathBuf>,
    pub source_path: Option<PathBuf>,

pub struct InstalledSet {
    tools: BTreeMap<String, Vec<InstalledTool>>,
}

impl InstalledSet {
    pub fn parse(json: &str) -> Result<Self, CoreError> {
        Ok(Self { tools: serde_json::from_str(json)? })
    }

    pub fn rows(&self, project_root: Option<&Path>) -> Vec<ToolRow> {
        let mut rows = Vec::new();
        for (name, versions) in &self.tools {
            for tool in versions {
                let path = tool.source.as_ref().and_then(|s| s.path.as_deref());
                let scope = match (project_root, path) {
                    (Some(root), Some(p)) if p.starts_with(root) => Scope::Project,
                    _ => Scope::Global,
                };
                rows.push(ToolRow {
                    name: name.clone(),
                    version: tool.version.clone(),
                    requested_version: tool.requested_version.clone(),
                    scope,
                    active: tool.active,
                    install_path: tool.install_path.clone(),
                    source_path: path.map(Path::to_path_buf),
                });
            }
        }
        rows.sort_by(|a, b| a.name.cmp(&b.name).then_with(|| a.version.cmp(&b.version)));
        rows
    }
}

    rows.iter()
        .filter(|r| match filter {
            ScopeFilter::All => true,
            ScopeFilter::Project => r.scope == Scope::Project,
            ScopeFilter::Global => r.scope == Scope::Global,
        })
        .cloned()
        .collect()
}
```

```rust
use crate::error::CoreError;
use serde::{Deserialize, Serialize};
use std::path::{Path, PathBuf};

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct Project {
    pub id: String,
    pub path: PathBuf,
    pub name: String,
}

#[derive(Debug, Clone, Default, PartialEq, Eq, Serialize, Deserialize)]
pub struct ProjectStore {
    pub projects: Vec<Project>,
    pub last_selected: Option<String>,
}

impl ProjectStore {
    pub fn add(&mut self, path: &Path) -> Result<&Project, CoreError> {
        let canonical = path.canonicalize()?;
        let id = canonical.to_string_lossy().into_owned();
        if let Some(idx) = self.projects.iter().position(|p| p.id == id) {
            return Ok(&self.projects[idx]);
        }
        let name = canonical
            .file_name()
            .map(|s| s.to_string_lossy().into_owned())
            .unwrap_or_else(|| id.clone());
        self.projects.push(Project { id, path: canonical, name });
        Ok(self.projects.last().expect("just pushed"))
    }

    pub fn remove(&mut self, id: &str) {
        self.projects.retain(|p| p.id != id);
        if self.last_selected.as_deref() == Some(id) {
            self.last_selected = None;
        }
    }

    pub fn load(path: &Path) -> Result<Self, CoreError> {
        if !path.exists() {
            return Ok(Self::default());
        }
        Ok(serde_json::from_str(&std::fs::read_to_string(path)?)?)
    }

    pub fn save(&self, path: &Path) -> Result<(), CoreError> {
        if let Some(parent) = path.parent() {
            std::fs::create_dir_all(parent)?;
        }
        std::fs::write(path, serde_json::to_string_pretty(self)?)?;
        Ok(())
    }
}

pub fn default_store_path() -> PathBuf {
    directories::ProjectDirs::from("dev", "mise-hub", "mise-hub")
        .map(|d| d.config_dir().join("projects.json"))
        .unwrap_or_else(|| PathBuf::from("projects.json"))
}
```

```rust
use std::io::{BufRead, BufReader};
use std::process::Stdio;
use std::sync::mpsc::{channel, Receiver};

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum StreamEvent {
    Stdout(String),
    Stderr(String),
    Exited(i32),
}

pub trait StreamingRunner: Send + Sync {
    fn spawn(&self, req: CommandRequest) -> Result<Receiver<StreamEvent>, CoreError>;
}

pub struct ProcessStreamer;

impl StreamingRunner for ProcessStreamer {
    fn spawn(&self, req: CommandRequest) -> Result<Receiver<StreamEvent>, CoreError> {
        let (tx, rx) = channel();
        std::thread::spawn(move || {
            let mut cmd = Command::new(&req.program);
            cmd.args(&req.args)
                .stdout(Stdio::piped())
                .stderr(Stdio::piped());
            if let Some(cwd) = &req.cwd {
                cmd.current_dir(cwd);
            }
            let mut child = match cmd.spawn() {
                Ok(c) => c,
                Err(e) => {
                    let _ = tx.send(StreamEvent::Stderr(e.to_string()));
                    let _ = tx.send(StreamEvent::Exited(-1));
                    return;
                }
            };
            let stdout = child.stdout.take();
            let stderr = child.stderr.take();
            let tx_out = tx.clone();
            let h_out = stdout.map(|s| {
                std::thread::spawn(move || {
                    for line in BufReader::new(s).lines().map_while(Result::ok) {
                        let _ = tx_out.send(StreamEvent::Stdout(line));
                    }
                })
            });
            let tx_err = tx.clone();
            let h_err = stderr.map(|s| {
                std::thread::spawn(move || {
                    for line in BufReader::new(s).lines().map_while(Result::ok) {
                        let _ = tx_err.send(StreamEvent::Stderr(line));
                    }
                })
            });
            let code = child.wait().ok().and_then(|s| s.code()).unwrap_or(-1);
            if let Some(h) = h_out { let _ = h.join(); }
            if let Some(h) = h_err { let _ = h.join(); }
            let _ = tx.send(StreamEvent::Exited(code));
        });
        Ok(rx)
    }
}
```

```rust
use crate::error::CoreError;
use crate::registry::parse_registry;
use crate::remote::parse_remote_versions;
use crate::runner::{CommandRequest, CommandRunner, StreamEvent, StreamingRunner};
use crate::tools::InstalledSet;
use crate::types::{RemoteVersion, ToolEntry};
use std::path::{Path, PathBuf};
use std::sync::mpsc::Receiver;
use std::sync::Arc;

pub struct Mise {
    program: PathBuf,
    runner: Arc<dyn CommandRunner>,
    streamer: Arc<dyn StreamingRunner>,
}

impl Mise {
    pub fn new(program: PathBuf, runner: Arc<dyn CommandRunner>, streamer: Arc<dyn StreamingRunner>) -> Self {
        Self { program, runner, streamer }
    }

    pub fn version(&self) -> Result<String, CoreError> {
        let out = self.run(&[], None)?;
        Ok(out.stdout.split_whitespace().next().unwrap_or_default().to_string())
    }

    pub fn registry(&self) -> Result<Vec<ToolEntry>, CoreError> {
        let out = self.run(&["registry", "--json"], None)?;
        parse_registry(&out.stdout)
    }

    pub fn installed(&self, project_root: Option<&Path>) -> Result<InstalledSet, CoreError> {
        let out = self.run(&["ls", "--json"], project_root)?;
        InstalledSet::parse(&out.stdout)
    }

    pub fn remote_versions(&self, tool: &str, project_root: Option<&Path>) -> Result<Vec<RemoteVersion>, CoreError> {
        let out = self.run(&["ls-remote", tool, "--json"], project_root)?;
        parse_remote_versions(&out.stdout)
    }

    pub fn install_stream(
        &self,
        tool: &str,
        version: &str,
        project_root: Option<&Path>,
    ) -> Result<Receiver<StreamEvent>, CoreError> {
        let spec = format!("{tool}@{version}");
        let mut args = self.base_args(project_root);
        args.extend(["install".into(), spec]);
        self.streamer.spawn(CommandRequest { program: self.program.clone(), args, cwd: None })
    }

    fn base_args(&self, project_root: Option<&Path>) -> Vec<String> {
        match project_root {
            Some(dir) => vec!["-C".into(), dir.to_string_lossy().into_owned()],
            None => vec![],
        }
    }

    fn run(&self, args: &[&str], project_root: Option<&Path>) -> Result<crate::runner::CommandOutput, CoreError> {
        let mut full = self.base_args(project_root);
        full.extend(args.iter().map(|s| s.to_string()));
        let out = self.runner.run(&CommandRequest {
            program: self.program.clone(),
            args: full,
            cwd: None,
        })?;
        if out.code != 0 {
            return Err(CoreError::CommandFailed { code: out.code, stderr: out.stderr });
        }
        Ok(out)
    }
}
```

```rust
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct AppSettings {
    pub theme: String,
    pub locale: String,
}

impl Default for AppSettings {
    fn default() -> Self {
        Self { theme: "Default Light".into(), locale: "en".into() }
    }
}

impl AppSettings {
    pub fn load(path: &Path) -> Result<Self, CoreError> {
        if !path.exists() {
            return Ok(Self::default());
        }
        Ok(serde_json::from_str(&std::fs::read_to_string(path)?)?)
    }

    pub fn save(&self, path: &Path) -> Result<(), CoreError> {
        if let Some(parent) = path.parent() {
            std::fs::create_dir_all(parent)?;
        }
        std::fs::write(path, serde_json::to_string_pretty(self)?)?;
        Ok(())
    }
}
```

```rust
use std::path::Path;

impl AppState {
    pub fn add_project(&mut self, path: &Path) -> Result<(), mise_core::CoreError> {
        self.projects.add(path)?;
        self.projects.save(&mise_core::default_store_path())?;
        Ok(())

    pub fn remove_project(&mut self, id: &str) {
        self.projects.remove(id);
        if self.selection.project_id() == Some(id) {
            self.selection = Selection::Discover;
        }
        let _ = self.projects.save(&mise_core::default_store_path());
    }

    pub fn rows(&self, filter: ScopeFilter) -> Vec<ToolRow> {
        match &self.installed {
            Loadable::Ready(rows) => filter_rows(rows, filter),
            _ => vec![],
        }
    }

    pub fn current_project_root(&self) -> Option<std::path::PathBuf> {
        let id = self.selection.project_id()?;
        self.projects.projects.iter().find(|p| p.id == id).map(|p| p.path.clone())
    }

    pub fn refresh_installed(&mut self) -> Result<(), mise_core::CoreError> {
        let Some(mise) = &self.mise else { return Ok(()); };
        let root = self.current_project_root();
        let set = mise.installed(root.as_deref())?;
        self.installed = Loadable::Ready(set.rows(root.as_deref()));
        Ok(())
    }
```

```rust
impl AppState {
    pub fn ensure_registry(&mut self) -> Result<(), mise_core::CoreError> {
        if matches!(self.registry, Loadable::Ready(_)) {
            return Ok(());
        }
        let Some(mise) = &self.mise else { return Ok(()); };
        self.registry = Loadable::Loading;
        match mise.registry() {
            Ok(entries) => {
                self.registry = Loadable::Ready(entries);
                Ok(())
            }
            Err(e) => {
                self.registry = Loadable::Failed(e.to_string());
                Err(e)
            }
        }
    }

    pub fn search(&self, query: &str, limit: usize) -> Vec<SearchHit> {
        match &self.registry {
            Loadable::Ready(entries) => SearchIndex::new(entries.clone()).search(query, limit),
            _ => vec![],
        }
    }
}
```

```rust
use mise_core::StreamEvent;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Stream { Stdout, Stderr }

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct TerminalLine { pub stream: Stream, pub text: String }

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum RunStatus { Running, Succeeded, Failed(i32) }

#[derive(Debug, Clone)]
pub struct TerminalSession {
    pub id: String,
    pub title: String,
    pub lines: Vec<TerminalLine>,
    pub status: RunStatus,
}

#[derive(Debug, Clone, Default)]
pub struct TerminalState {
    pub sessions: Vec<TerminalSession>,
    pub active: usize,
    pub visible: bool,
}

impl TerminalState {
    pub fn begin(&mut self, title: impl Into<String>) -> String {
        let id = format!("term-{}", self.sessions.len() + 1);
        self.sessions.push(TerminalSession {
            id: id.clone(),
            title: title.into(),
            lines: vec![],
            status: RunStatus::Running,
        });
        self.active = self.sessions.len() - 1;
        self.visible = true;
        id
    }

    pub fn active_session(&self) -> Option<&TerminalSession> {
        self.sessions.get(self.active)
    }

    pub fn push_event(&mut self, event: StreamEvent) {
        let Some(session) = self.sessions.get_mut(self.active) else { return; };
        match event {
            StreamEvent::Stdout(text) => session.lines.push(TerminalLine { stream: Stream::Stdout, text }),
            StreamEvent::Stderr(text) => session.lines.push(TerminalLine { stream: Stream::Stderr, text }),
            StreamEvent::Exited(0) => session.status = RunStatus::Succeeded,
            StreamEvent::Exited(code) => session.status = RunStatus::Failed(code),
        }
    }
}
```

在视图里用 GPUI 的异步任务消费事件，**不要跨线程直接更新 Entity**：

```rust
fn run_install(&mut self, tool: String, version: String, cx: &mut Context<RootView>) {
    let rx = match self.state.start_install(&tool, &version) {
        Ok(rx) => rx,
        Err(e) => {
            self.state.terminal.begin(format!("install {tool}@{version}"));
            self.state.terminal.push_event(mise_core::StreamEvent::Stderr(e.to_string()));
            self.state.terminal.push_event(mise_core::StreamEvent::Exited(-1));
            cx.notify();
            return;
        }
    };

    // std 接收器在后台线程里转到 async channel；UI 线程只 await，不跨线程碰 Entity。
    let (tx, async_rx) = async_channel::unbounded();
    std::thread::spawn(move || {
        for event in rx {
            if tx.send_blocking(event).is_err() {
                break;
            }
        }
    });

    cx.spawn(async move |this, cx| {
        while let Ok(event) = async_rx.recv().await {
            this.update(cx, |state, cx| {
                state.terminal.push_event(event);
                cx.notify();
            })
            .ok();
        }
    })
    .detach();
}
```

> 需要 `use gpui_kit::AppContext as _;` 才能调用 `cx.spawn`。`this.update(cx, ..)` 的第二个参数是 `&mut Context<T>`，可以直接 `cx.notify()`。
